# Android 手机远控

Android 浏览器提供 HappyPanda 的遥控界面。PC 上的 `AppController` 继续管理 SSH、同步、原生终端和本地 MCP；手机通过单独的 HTTP 接口和事件流接入该控制器。

```text
Android 浏览器 <-> PC 远控接口 <-> AppController <-> SSH / 远端 Claude Code
                                     |
                                PC 本地 MCP
```

## 使用

先构建并运行当前版本，或者使用包含此功能的桌面分发包：

```powershell
npm run build
npm start
```

点击工具栏的手机图标，开启“允许手机远控”。选择 PC 的局域网地址；存在多块网卡时，地址列表保留其他网卡供切换。Android 与 PC 连接同一局域网后扫描二维码即可配对，也可以在手机浏览器打开连接地址并输入 8 位配对码。需要 Windows 网络访问许可时，允许当前使用的专用网络。

手机点击“接管控制”后，可以连接节点、切换已有工作区和会话、选择提供商、输入终端命令、处理同步冲突和上传图片。输入框支持中文输入法，Enter 发送，Shift+Enter 换行；工具栏提供 Esc、Tab、Ctrl+C、方向键和回车。图片经过浏览器转换为 PNG，由 PC 沿用现有上传流程送到当前会话。

PC 和手机共享当前活动会话。当前控制端决定终端尺寸，其他端按实际尺寸显示并支持滚动，避免两个界面反复修改同一个终端。配对完成不自动接管输入；PC 可随时通过横幅、设置或托盘收回控制权。

终端尺寸变化以私有 OSC 7337 标记写入输出流本身（与 asciinema 记录 resize 事件的做法相同）。非控制端在解析到标记的位置切换尺寸，因此尺寸变化与输出顺序一致；重连或切换会话后回放的缓冲区也会在原来的位置切换尺寸。缓冲区裁剪时保留起点处生效的尺寸。控制端只要发现 PTY 尺寸与自身不一致就重新发送尺寸，因此收回控制权后 PC 窗口即使处于隐藏或尺寸未变，也会恢复到 PC 的尺寸。终端使用 WebGL 渲染（不可用时回退 DOM）和 Unicode 11 字宽表，与 Claude Code 的 emoji 和中文宽度一致。

手机竖向拖动终端时按行滚动历史，松手后带惯性继续滚动（类似 Termux）；横向拖动仍由浏览器处理，用于平移较宽的观察画面。备用屏幕（如 less、vim）没有滚动历史，取得控制权时拖动会发送方向键。PC 把连续的终端输出合并为约 16 ms 一帧再发给手机，其他事件之前会先发出已合并的输出。
远控开启期间，关闭 PC 窗口会隐藏到托盘。手机刷新、断网或切换后台不会主动断开 PC 的 SSH 和同步，也不会取消正在执行的任务。重新连接时重新获取完整状态和终端缓冲区；中断期间的按键和命令不会自动补发。完全退出 HappyPanda 或 PC 睡眠后，远控入口不可用。

## 接入与权限

远控默认关闭。每次配对使用 5 分钟内有效的一次性 8 位码和独立的高随机性扫码凭据。手机使用 HttpOnly、SameSite=Strict Cookie，PC 只持久化设备令牌摘要。配对凭据与 MCP 的 Bearer 令牌独立。已配对设备可在 PC 上单独撤销，撤销会关闭该设备的事件流并拒绝后续请求。

远控接口校验 Host、Origin、请求方法、参数、大小和控制权。终端输入、尺寸更新及图片上传绑定活动节点与会话；切换会话、重连、更换控制端或撤销设备后，过时的请求会被拒绝。本地 MCP 保持原有 loopback 监听、SSH 反向隧道和工作区权限。

关闭远控只停止手机连接，保留已配对设备，并将控制权交回 PC。再次开启和重启 PC 应用后可沿用未过期的配对记录；重启后不自动恢复手机控制权。配对记录默认有效 30 天。

## 当前范围

这一版面向 Android 浏览器和局域网，没有公网中继或独立 APK。本地目录选择和打开、官方账号专用授权浏览器仍由 PC 完成。手机端切换已经在 PC 上添加的工作区；本机预览端口和 localhost 链接在 PC 上打开。

桌面开发服务器的普通浏览器预览仍没有 Electron IPC。远控页面由 PC 主进程提供构建后的 `out/renderer`，入口为设置中显示的 `/remote/` 地址；修改手机界面后需要重新构建。远控开关、设备摘要和监听端口保存在应用数据目录的 `remote-control.json`，不写入项目工作区。

## 验证

```powershell
npm run typecheck
npm test
npm run build
npm run smoke:remote-control
npm run smoke:remote-control:package -- "打包后的 EXE 路径"
```

传输测试覆盖配对、撤销、控制权、同源限制、参数验证、状态恢复和中断后不重发。运行时测试把远控输入写入真实 PC PTY，并通过原本的 MCP 接口执行本地文件读取和命令。Electron 冒烟使用隔离数据目录验证桌面入口、二维码、后台运行和设备撤销，不连接用户的 SSH 节点或请求模型。

分发包冒烟直接启动指定 EXE，检查 ASAR 封装后的 HTML、JavaScript 和 CSS 资源能否通过远控接口读取，并完成真实配对、接管、撤销和关闭远控。调试端口只在这次本机测试中启用，测试程序退出后关闭。
