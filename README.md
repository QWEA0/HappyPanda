# HappyPanda

HappyPanda 是一款桌面端最小可行产品（MVP），用于在已保存的 SSH 节点上运行原版 Claude Code CLI。默认在远程服务器上进行开发。本地项目可通过 Mutagen 双向同步建立镜像；需要使用本地计算机的工作流还可以按需启用本地 MCP 工具。

React 界面已实现并接入桌面 API，支持节点保存、SSH 别名、工作区、原生 CLI 终端、tmux 会话重连、多个第三方 API 提供商与切换重载、服务器指标、同步与冲突处理、本地 MCP 设置、预览端口转发，以及本地历史记录的导入和接续。

## 搭建开发环境

前置条件：

- Node.js 22.12 或更新版本，以及 npm。
- 系统 OpenSSH、已信任的远程主机密钥，以及可用的 SSH 身份认证。
- 远程服务器已安装 Python 3、tmux 和 Claude Code CLI。
- 已启用 SSH 转发，用于 MCP 桥接和预览隧道。

在项目根目录执行：

```powershell
npm ci
npm run install:sync
npm run dev
```

`install:sync` 会将 Mutagen 及其代理程序归档安装到 `.local/tools`。请在打包前完成安装，确保打包配置中的额外资源可用。桌面开发启动脚本会移除子进程中的 `ELECTRON_RUN_AS_NODE` 环境变量，并在需要时运行 Electron 二进制安装程序。

MVP 使用 node-pty 的 N-API 预编译二进制文件，electron-builder 配置为 `npmRebuild: false`。Windows 开发环境中的 PTY 验证结果不代表打包后的图形界面已通过完整验收。

本地渲染进程预览地址为 `http://127.0.0.1:5173`，在浏览器中仅供界面预览。该预览不具备桌面 IPC 能力，会将配置中的初始节点显示为未连接；依赖桌面能力的操作会报错，提示需要在桌面应用中执行。需要调用 API 的工作流请使用 Electron 窗口。

## 使用 MVP

1. 打开桌面应用。首次启动没有预置节点，点击“新增节点”配置自己的服务器。添加或编辑节点时，可以填写 SSH 别名或主机地址，并按需覆盖用户名、端口和 IdentityFile。已有本机保存的节点、工作区和会话会继续保留。
2. 点击节点进行连接。通过工作区选择器选择本地项目目录，应用会记住其映射和会话。SSH 会先接通，工作区在后台同步；首次同步和 Git 准备完成前，终端显示等待提示，随后自动启动 Claude。选择已有会话不会再因两分钟同步等待而断开 SSH。中央的 xterm 终端显示真实的远程 CLI 和 SSH PTY 输出。
3. 使用官方账号时，点击“通过当前服务器登录”。客户端为节点建立 SSH 代理，使用独立 Chrome / Edge 配置打开官方授权页面，浏览器路由通过验证后才跳转授权；登录完成后自动重载并返回原 Claude 会话。如果页面给出授权码，在当前终端粘贴即可。使用第三方 API 时，打开右侧“API 提供商”的管理按钮，新增名称、Base URL 和密钥；返回侧栏选择提供商，点击“应用并重载 Claude”。配置列表在本机共用，每个服务器单独记住所选项，支持随时切回“官方账号”。高级设置支持 Bearer Token / x-api-key、指定模型、关闭非必要网络请求。服务必须兼容 Anthropic 接口，API 配置已保存不代表真实模型调用已验证。
4. 使用同步后的项目镜像进行远程开发。连接工作区或点击立即同步时，会从 Git 读取当前被忽略且未跟踪的文件与目录，连同依赖、缓存一起排除；已跟踪文件仍参与同步。忽略目录采用稳定的目录规则，保留其中已跟踪文件的例外，新增报告或缓存不会反复重建同步会话。确实需要更新范围时，先完成旧会话的同步；存在冲突或同步错误时保留旧会话处理，避免丢失同步基线。侧边栏显示实测服务器指标、同步状态、冲突、最近会话和活动记录。选择本地或远程版本即可解决冲突。断开并重新连接后，远程 tmux 会话仍会保留。
5. 本地 MCP 默认关闭。需要本地工具时，可为所选工作区启用，访问控制会立即生效。文件工具的访问范围限制在工作区根目录内；Shell 命令以本地用户权限运行，不属于操作系统沙箱。Windows 使用 PowerShell/pwsh，尚未适配 Git Bash 和 WSL；Unix 主机使用 bash/sh。
6. 使用端口转发（Port forwarding），将服务器端口映射到本地回环端口。打开分配的 `http://127.0.0.1:<localPort>` 即可查看远程预览。该对话框可移除本次应用运行期间创建的转发记录。
7. 使用导入本地历史记录（Import local history），选择本地会话，复制其 JSONL 和子代理记录，并通过远程 CLI 继续已导入的会话。原始文件会保留。附件、回退状态和运行时上下文不会完整迁移，也不会复制 OAuth 凭据。
8. 在工作区区域点击“导入本机项目记忆”，将对应项目的 Claude 自动记忆 Markdown 文件复制到远端项目记忆目录。导入会逐份校验内容，相同文件跳过、不同的同名文件保留远端版本并列出差异。它与会话历史导入分开，不会自动重载当前对话；当前会话可以重新读取 MEMORY.md，新会话自动加载记忆索引。

工作文件双向同步，`.git` 不参与文件同步。远端 `workspace` 分支由本机初始 HEAD 建立；文件就绪后，应用自动检查远端提交，通过增量 Git bundle 取回到本机独立引用，并在历史允许快进时更新本机当前分支及对应的索引条目。已被远端提交包含的暂存快照会归入该提交，其他暂存和未暂存内容保留；更新前备份本机索引。分支分叉、重定向 HEAD、进行中的 Git 操作或重叠的暂存冲突会显示“提交待处理”，传输失败显示“提交同步失败”。“立即同步”也会立即检查提交；应用不会自动创建合并提交或推送。不要同时在两端切分支或清理工作区，这些操作产生的文件变化也会回传。远端 Git 会采用本机的换行符和文件模式比较设置，避免 Windows/Linux 差异导致数百个文件被误报为修改。

截图或复制图片后，点击已连接的终端，按 `Ctrl+V`（也支持 `Ctrl+Shift+V`、macOS `Cmd+V`），或点击“粘贴到终端”。图片上传完成后，输入区会出现服务器图片路径；补充说明后按 Enter 发送。截图保存在服务器的应用附件目录，独立于项目和 Git；无需先保存到项目、开启本地 MCP 或等待文件同步。文字剪贴板仍按文字粘贴。上传失败、断线或切换会话时不会把图片填进其他终端。当前支持系统剪贴板中的 PNG 图片，单张最多 20 MiB；从文件管理器复制图片文件与复制图片内容不同。

提供商密钥通过系统加密服务保存在应用数据目录中；编辑时留空保留原密钥，不会向界面回传已保存的密钥。远程会话配置通过 SSH 标准输入传输，写入应用自己的私有运行目录，不修改 shell 配置或项目中的 Claude 设置。重载会中断当前任务并恢复已保存的对话，终端里尚未提交的输入不保留；其他 tmux 会话在下次接回时应用新的提供商。普通“重新连接”在配置未变时继续保留原进程。

节点登录浏览器不使用日常浏览器配置，Cookie 按节点独立保留。HTTP(S) 与登录的 localhost 回调都通过当前节点的 SOCKS5 通道；禁止代理直连回退，并限制 QUIC 和非代理 WebRTC UDP。隧道中断后，专用本地代理端口仍保留并拒绝连接。采用此登录方式的节点，其官方 Claude 会话会清理继承的代理变量，直接从节点出站。该功能统一的是节点网络路由，浏览器仍运行在本机；不能保证服务方无法识别代理、VPS 或设备环境，也不能保证账号不会受限。

每次登录只自动打开 Claude 的浏览器启动钩子给出的链接。终端中的备用链接使用不同的授权码回调，保留手动点击，不会同时自动打开第二个窗口。客户端会通过同一代理检查公开授权页及入口脚本，显示超时、HTTP 错误或网站验证提示；“通道已连通”不等于网页已渲染或账号已登录。重新登录会关闭应用管理的旧登录窗口，生成新的授权流程。

## 构建与检查

```powershell
npm run typecheck
npm run test
npm run build
npm run pack
npm run smoke:remote -- your-ssh-alias
npm run smoke:providers -- your-ssh-alias
npm run smoke:login -- your-ssh-alias
npm run smoke:clipboard
python tests/provider_runtime_test.py
python tests/image_upload_test.py
```

- `typecheck`：检查共享 API、渲染进程、主进程、TypeScript 配置涵盖的脚本，以及测试代码的类型。
- `test`：运行单元测试，覆盖节点清单与 SSH 处理、同步、MCP 访问边界与操作生命周期、历史记录和连接。测试结果及数量以当前测试输出为准。
- `build`：编译 Electron 主进程、预加载脚本和渲染进程。
- `pack`：构建未封装为安装程序的桌面分发包。每次输出到独立的 `release/build-<时间戳>-<进程号>/`，Windows x64 可执行文件在其 `win-unpacked/HappyPanda.exe` 下，避免重打包破坏正在运行的旧版本。打包前检查远端脚本和同步工具，Windows 打包后再次检查资源完整性。`portable` 使用同样流程生成 Windows 便携包。
- 远程冒烟脚本需要显式指定 SSH 目标，不内置个人服务器。`smoke:remote`、`smoke:providers`、`smoke:login` 和 `proof` 可通过首个参数或 `HAPPYPANDA_SMOKE_NODE` 环境变量指定；`smoke:clipboard` 使用该环境变量。
- `smoke:remote`：针对指定的 SSH 目标运行真实 VPS 回归测试，创建测试工作区、同步会话和 tmux 会话。脚本会写入 `.local/remote-smoke-result.json`。完整测试数据回归已通过，具体测试范围请查看结果文件。
- `smoke:providers`：使用真实 VPS 的隔离 tmux 服务、合成密钥和模拟 CLI，验证提供商切换、更换进程、恢复会话、重连幂等、凭据隔离及切回官方模式；结果保存到 `.local/provider-smoke-result.json`，不发起模型请求。
- `smoke:login`：验证真实 SSH SOCKS、远程 localhost 回调、浏览器访问探测、断线拒绝连接与过期授权阻断，结果保存到 `.local/login-browser-smoke-result.json`。浏览器导航由合成 HTTP 请求模拟，不完成真实 OAuth 登录。
- `smoke:clipboard`：使用测试图片、真实 Windows 剪贴板、构建后的终端界面和独立远端 Shell，验证 Ctrl+V、粘贴按钮、文字回归与图片 SHA-256。测试结束恢复原剪贴板；若期间用户已复制新内容则保留新内容。结果保存在 `.local/clipboard-smoke-result.json`，不调用模型。
- `python tests/provider_runtime_test.py`：验证远程启动参数、环境冲突清理、导入后对话续接与重载逻辑，不需要 SSH 或模型密钥。

历史记录传输会校验 SHA-256，并跳过已完整传输且校验一致的文件。传输中断留下的 `.part` 文件会重新完整上传，这是整文件重试，不支持按字节断点续传。
